```bash
cd ~/Documents/english
cp "CET4_2026年6月第2套_阅读题路精讲.html" cet4-site/cet4-2026-06-set2.html
cp "CET4_2026年6月第3套_阅读题路精讲.html" cet4-site/cet4-2026-06-set3.html
```

## 笔记与备份

- 手写笔记保存在**浏览器 localStorage**，绑定当前网址 origin（换端口/换域名＝换存储）。
- 学完请在页内点「一键导出」备份到文件 App / 云端。
- 清除 Safari 网站数据会清空该网页笔记。
